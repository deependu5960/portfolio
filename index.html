Demo
Security Awareness Project
Fake Login & Location Capture Demo

An educational demonstration showing how phishing pages can collect user information and location data. Built only to demonstrate phishing techniques and improve security awareness.

HTML CSS JavaScript Geolocation API
GitHub

Educational Purpose

This project is built purely for educational purposes to demonstrate how phishing pages work. It helps understand the importance of security awareness and why users should be careful about what information they share online.

How Phishing Works

  • Attackers create fake login pages that mimic legitimate sites
  • Users enter their credentials thinking it's a trusted site
  • Information is captured and can be misused
  • Location data can also be collected if permissions are granted

Ethical Usage

  • This demo is for learning and awareness only
  • Never use this for malicious purposes
  • Always get proper authorization for any security testing
  • Use this knowledge to help others stay safe online

Security Lessons Learned

  • Always check URL before entering credentials
  • Be cautious about granting location permissions
  • Use two-factor authentication when possible
  • Never reuse passwords across sites
